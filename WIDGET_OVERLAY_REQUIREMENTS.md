# ТРЕБОВАНИЯ К ВИДЖЕТУ - OVERLAY MODE

## 🎯 ОСНОВНАЯ ИДЕЯ

Виджет должен **БЛОКИРОВАТЬ** работу в amoCRM пока не начата рабочая смена!

---

## 📋 ФУНКЦИОНАЛЬНОСТЬ

### 1. ПРИ ЗАГРУЗКЕ amoCRM (смена не начата)
```
┌─────────────────────────────────────────┐
│  ВСЯ СТРАНИЦА amoCRM                    │
│                                         │
│  ╔═══════════════════════════════════╗  │
│  ║  ПОЛУПРОЗРАЧНЫЙ ОВЕРЛЕЙ           ║  │
│  ║  (блокирует все кнопки)           ║  │
│  ║                                   ║  │
│  ║    ⏰ Табель учёта времени         ║  │
│  ║                                   ║  │
│  ║    Начните рабочий день!          ║  │
│  ║                                   ║  │
│  ║    [▶️ Начать смену]              ║  │
│  ║                                   ║  │
│  ╚═══════════════════════════════════╝  │
└─────────────────────────────────────────┘
```

**Эффект:**
- ❌ Нельзя кликать на сделки
- ❌ Нельзя открывать контакты
- ❌ Нельзя создавать задачи
- ✅ Видна только кнопка "Начать смену"

---

### 2. ПОСЛЕ НАЖАТИЯ "НАЧАТЬ СМЕНУ"
```
┌─────────────────────────────────────────┐
│  ВСЯ СТРАНИЦА amoCRM                    │
│  (ПОЛНОСТЬЮ ДОСТУПНА!)                  │
│                                         │

│  │ ⏰ Таймер: 00:15:23      │ (вверху) │
│  │ [⏸️ Перерыв] [⏹️ Стоп]   │           │
│  └──────────────────────────┘           │
│                                         │
│  ✅ Все кнопки работают                 │
│  ✅ Можно работать со сделками          │

```

**Эффект:**
- ✅ Overlay исчез
- ✅ Можно работать в amoCRM
- ✅ Виджет свернут в угол с таймером

---

### 3. ПОСЛЕ НАЖАТИЯ "ПЕРЕРЫВ"
```
┌─────────────────────────────────────────┐
│  ВСЯ СТРАНИЦА amoCRM                    │
│                                         │
│  ╔═══════════════════════════════════╗  │
│  ║  ПОЛУПРОЗРАЧНЫЙ ОВЕРЛЕЙ           ║  │

│  ║    Таймер: 00:15:23 (остановлен)  ║  │
│  ║                                   ║  │
│  ║    [▶️ Продолжить] [⏹️ Завершить] ║  │
```

**Эффект:**
- ❌ Overlay ВЕРНУЛСЯ
- ❌ Нельзя работать в amoCRM
- ✅ Можно продолжить или завершить

## 🎯 ЛОГИКА

### Состояния overlay:
1. **ПОКАЗАН:** Когда статус = "idle" (не начата) или "break" (перерыв)
2. **СКРЫТ:** Когда статус = "working" (работаю)

### JavaScript:
```javascript
showOverlay()  // Показать оверлей
hideOverlay()  // Скрыть оверлей

При "Начать смену" → hideOverlay()
При "Перерыв" → showOverlay()
При "Продолжить" → hideOverlay()
При "Завершить" → showOverlay()
```
