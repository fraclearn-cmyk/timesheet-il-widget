## 🎯 ЦЕЛИ ЭТАПА

Реализовать API для экспорта отчётов в Excel с фильтрацией по RBAC:
- Отчёт по подразделениям
- Отчёт по сотрудникам
- Опоздания
- Комментарии РОП
- Excel экспорт с форматированием

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Excel библиотека
Использовать: `openpyxl` (уже в requirements.txt?)

### Фильтры
- Период: date_from, date_to
- Подразделение: department_id (с RBAC)
- Сотрудник: user_id (с RBAC)
- Только опоздавшие: late_only

### RBAC
- РОП: только свои подразделения
- Админ: все подразделения
- Сотрудник: запрещено

### Формат Excel
- Заголовок с фильтрами
- Таблица с данными
- Итоговая строка
- Форматирование (жирный, цвета)

## 📊 СТРУКТУРА ОТЧЁТОВ

### 1. Department Report
Колонки:
- Подразделение
- Сотрудник
- Дата
- Начало работы
- Конец работы
- Время работы (часы)
- Время на перерывах
- Опоздание (мин)
- Комментарий РОП

### 2. Employee Report
Колонки:
- Дата
- День недели
- Начало
- Конец
- Работа (ч:мм)
- Перерывы (ч:мм)
- Опоздание (мин)
- Причина опоздания
- Принудительное завершение
- Комментарий РОП

### 3. Late Arrivals Report
Колонки:
- Дата
- Сотрудник
- Подразделение
- Норма начала
- Фактическое начало
- Опоздание (мин)
- Причина
- Комментарий РОП
