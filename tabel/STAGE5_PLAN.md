## 🎨 OVERLAY СОСТОЯНИЯ

### 1. BEFORE_WORKDAY
**Экран:** "Начните рабочий день"
- Кнопка "НАЧАТЬ"
- Проверка расписания
- Расчёт опоздания

### 2. LATE
**Экран:** "Вы опоздали"
- Показать минуты опоздания
- **Обязательное** поле причины
- Кнопка "НАЧАТЬ РАБОТУ"
- Минимум 10 символов

### 3. WORKING
**Компактный виджет справа вверху:**
- Таймер работы
- Статус CRM (активен/неактивен)
- Кнопка "ПЕРЕРЫВ"
- Кнопка "ЗАВЕРШИТЬ"

### 4. BREAK
**Большой экран:**
- Таймер перерыва
- Предупреждение > 15 мин
- Кнопка "ВЕРНУТЬСЯ К РАБОТЕ"
- История перерывов сегодня

### 5. FINISHED
**Экран итогов:**
- Отработано времени
- Количество перерывов
- Статистика дня
- Кнопка "НАЧАТЬ" (если < 23:00 и разрешено)

## 🔌 API ИНТЕГРАЦИЯ

### Endpoints использовать:
- `GET /api/v1/sessions/current` - текущая сессия
- `POST /api/v1/sessions/start` - начать работу
- `POST /api/v1/sessions/break` - перерыв
- `POST /api/v1/sessions/resume` - возврат
- `POST /api/v1/sessions/finish` - завершить
- `GET /api/v1/kpi/my` - мои KPI
- `GET /api/v1/kpi/chart/my?days=7` - график

### Headers:
- `X-User-Id`: amoCRM user ID
- `X-Account-Id`: amoCRM account ID
