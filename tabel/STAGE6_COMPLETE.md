## 🔌 API ИНТЕГРАЦИЯ

**Используемые endpoints:**
- `GET /api/v1/team/status` - список сотрудников
- `GET /api/v1/team/stats` - статистика команды
- `GET /api/v1/team/timeline/{user_id}` - timeline пользователя
- `POST /api/v1/team/force-finish/{user_id}` - force finish
- `GET /api/v1/kpi/department/{id}` - KPI подразделения
- `GET /api/v1/kpi/chart/department/{id}?days=X` - график
