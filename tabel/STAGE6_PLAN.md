## 🎨 ИНТЕРФЕЙС РОП

### Главный экран

**Фильтры:**
- Все / Онлайн / Работают / На перерыве / Завершили
- Поиск по имени

**Карточки сотрудников:**
```
┌─────────────────────────────┐
│ 👤 Иван Иванов              │
│ ⚡ Работает 3:45             │
│ 📊 Сегодня: 3.8ч / 8ч      │
│ [Timeline] [Force Finish]   │
└─────────────────────────────┘
```

**Статусы:**
- 🟢 Работает (зелёный)
- 🟡 На перерыве (жёлтый)
- ⚫ Не начал (серый)
- ✅ Завершил (синий)
- 🔴 Неактивен >5мин (красный)

### Timeline модальное окно

**96 интервалов по 15 минут (00:00 - 23:59):**
```
09:00 ▓▓▓▓░░▓▓▓▓▓▓▓▓ 17:00
      │││││││││││││
      работа│перерыв│работа
```

**Легенда:**
- ▓ Работа (зелёный)
- ░ Перерыв (жёлтый)
- □ Не начато (серый)
- ✓ CRM активность (точки)

## 🔌 API ИНТЕГРАЦИЯ

### Endpoints использовать:
- `GET /api/v1/team/status` - статус команды
- `GET /api/v1/team/stats` - статистика
- `GET /api/v1/team/activity` - активность
- `GET /api/v1/team/timeline/{user_id}` - timeline сотрудника
- `GET /api/v1/team/history` - история сессий
- `POST /api/v1/team/force-finish/{user_id}` - принудительное завершение
- `GET /api/v1/kpi/department/{id}` - KPI подразделения
- `GET /api/v1/kpi/chart/department/{id}?days=7` - график

### Headers:
- `X-User-Id`: РОП user ID
- `X-Account-Id`: amoCRM account ID
