### 2. KPI Service (1 файл)
**backend/app/services/kpi_service.py**

- get_chart_data() - данные для графиков (7/30 дней)

### 3. API Endpoints (1 файл)
**backend/app/api/v1/endpoints/kpi.py**

- GET /kpi/user/{id} - KPI пользователя (ROP/Admin)
- GET /kpi/department/{id} - KPI подразделения (ROP/Admin)
- GET /kpi/chart/{type} - данные графика
- GET /dashboard/settings - настройки
- PUT /dashboard/settings - обновить настройки

## 📊 KPI МЕТРИКИ

### Для сотрудника:
- Рабочие часы (сегодня/неделя/месяц)
- Среднее время работы в день
- Количество опозданий
- Процент выполнения нормы
- Статус (работает/перерыв/завершил)

### Для подразделения (ROP):
- Количество сотрудников
- Online сейчас
- Средние часы по подразделению
- Количество опозданий
- Лучшие/худшие показатели

### Графики:
- Динамика рабочих часов (7/30 дней)
- Опоздания за период
- Сравнение с прошлым периодом
- Распределение по дням недели

---

## 🔐 RBAC

- Employee: только свои KPI
- ROP: свои + подразделения + сотрудники подразделений
- Admin: все
