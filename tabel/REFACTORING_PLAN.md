# ПЛАН ДОРАБОТКИ ВИДЖЕТА «ТАБЕЛЬ IL»

## АНАЛИЗ ТЕКУЩЕГО ПРОЕКТА

### ✅ Что УЖЕ ЕСТЬ:
- **Модели БД**: WorkSession, StatusTransition, ActivitySession, ActivityEvent, Report
- **API**: sessions, activity, team, reports, settings, categories
- **Статусы**: WORKING, BREAK, FINISHED
- **Widget**: overlay система, таймеры, блокировка
- **Activity tracking**: отслеживание событий CRM

### ❌ Чего НЕТ (требуется по ТЗ):
1. **RBAC** - роли и права доступа (Сотрудник/РОП/Администратор)
2. **Опоздания** - проверка времени начала работы, причина опоздания
3. **Расписание подразделений** - начало/конец рабочего дня
4. **Командный интерфейс** - список сотрудников с realtime статусами
5. **Timeline активности** - горизонтальная временная шкала с цветами
6. **Расширенный отчёт** - таблица с фильтрами, pagination
7. **Excel экспорт** - настраиваемые колонки, несколько листов
8. **KPI dashboard** - настраиваемые карточки для РОП/Админ
9. **Графики** - настраиваемые показатели
10. **Принудительное завершение** - только для Администратора
11. **Повторный запуск** - настраиваемое разрешение
12. **Комментарии РОП** - к рабочим дням сотрудников
