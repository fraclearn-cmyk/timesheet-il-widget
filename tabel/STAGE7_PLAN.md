## 🎨 ИНТЕРФЕЙС АДМИНА

### Tab 1: Подразделения

**Список подразделений (таблица):**
```
┌────────────────────────────────────────────────────┐
│ Название    │ РОП         │ Сотрудников │ Действия│
│ Отдел 1     │ Иванов И.   │ 12          │ [✏️][🗑️]│
│ Отдел 2     │ Петров П.   │ 8           │ [✏️][🗑️]│
└────────────────────────────────────────────────────┘
[+ Добавить подразделение]
```

**Функции:**
- Создать подразделение
- Редактировать название
- Назначить РОПа
- Удалить подразделение

### Tab 2: Пользователи

**Список всех пользователей (таблица):**
```
┌──────────────────────────────────────────────────────────┐
│ Имя       │ Подразделение │ Роль     │ Статус  │ Действия│
│ Иванов И. │ Отдел 1       │ ROP      │ Активен │ [✏️]    │
│ Петров П. │ Отдел 1       │ Employee │ Работает│ [✏️]    │
└──────────────────────────────────────────────────────────┘
```

**Фильтры:**
- По подразделению
- По роли (Admin / ROP / Employee)
- По статусу (Активен / Работает / Перерыв / Неактивен)
- Поиск по имени

**Функции:**
- Изменить роль пользователя
- Переместить в другое подразделение
- Деактивировать пользователя

### Tab 3: Настройки

**График работы:**
- Начало рабочего дня (default: 09:00)
- Опоздание после (default: 09:15)
- Норма часов в день (default: 8)
- Максимальное время перерыва (default: 60 мин)
- Предупреждение перерыва (default: 15 мин)

**Уведомления:**
- Email уведомления РОПам
- Частота отчётов
- Webhook URL для интеграций

### Tab 4: Статистика

**Глобальные метрики:**
- Всего пользователей
- Всего подразделений
- Активных сессий сегодня
- Средние часы по системе
- Топ 5 подразделений по часам
- График активности (7/30 дней)

## 🔌 API ИНТЕГРАЦИЯ

### Используемые endpoints:

**Departments:**
- `GET /api/v1/departments` - список
- `POST /api/v1/departments` - создать
- `PUT /api/v1/departments/{id}` - обновить
- `DELETE /api/v1/departments/{id}` - удалить
- `PUT /api/v1/departments/{id}/schedule` - настройки графика

**Users (новый модуль):**
- `GET /api/v1/users` - список всех пользователей
- `PUT /api/v1/users/{id}/role` - изменить роль
- `PUT /api/v1/users/{id}/department` - переместить

**ROP Permissions:**
- `POST /api/v1/rop-permissions` - назначить РОПа
- `DELETE /api/v1/rop-permissions/{id}` - удалить РОПа

**Stats (новый):**
- `GET /api/v1/admin/stats` - глобальная статистика

### Headers:
- `X-User-Id`: Admin user ID
- `X-Account-Id`: amoCRM account ID
