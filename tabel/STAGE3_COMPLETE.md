### 2. Excel Service
**Файл:** `backend/app/services/excel_service.py` (создан, 280 строк)

**3 метода генерации отчётов:**

**generate_department_report()**
- Отчёт по подразделениям
- Колонки: Подразделение, Сотрудник, Дата, Начало, Конец, Работа, Перерывы, Опоздание, Комментарий
- Итоговая строка с суммами
- Фильтры: department_ids, late_only, include_comments

**generate_employee_report()**
- Отчёт по конкретному сотруднику
- Колонки: Дата, День недели, Начало, Конец, Работа, Перерывы, Опоздание, Принуд. завершение, Комментарий
- Итоговая строка: дней, времени, опозданий
- Формат времени: HH:MM

**generate_late_arrivals_report()**
- Отчёт по опозданиям
- Колонки: Дата, Сотрудник, Подразделение, Начало, Опоздание (мин), Причина, Комментарий РОП
- Красный заголовок для визуального выделения
- Итого: количество и общее время опозданий

**Общие фичи:**
- Форматирование: жирные заголовки, цветные ячейки
- Авто-ширина колонок
- Заголовок с периодом и временем формирования
- Возврат BytesIO для streaming

### 3. API Endpoints
**Файл:** `backend/app/api/v1/endpoints/excel.py` (создан, 200 строк)

**POST /api/v1/excel/department**
- Экспорт отчёта по подразделениям
- RBAC: РОП видит только свои подразделения, Админ - все
- Проверка доступа к запрошенным подразделениям
- StreamingResponse с корректным Content-Disposition

**POST /api/v1/excel/employee/{employee_id}**
- Экспорт отчёта по сотруднику
- RBAC: проверка доступа к сотруднику через can_view_employee()
- Только РОП/Админ
- Имя файла включает имя сотрудника

**POST /api/v1/excel/late-arrivals**
- Экспорт отчёта по опозданиям
- RBAC: фильтрация по доступным подразделениям
- Только РОП/Админ
- Показывает причины опозданий и комментарии РОП

### 4. Интеграция

- Добавлен import: `from app.api.v1.endpoints import excel`
