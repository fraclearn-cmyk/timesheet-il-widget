4. Загрузить виджет в amoCRM
5. Протестировать все функции

```bash
docker --version

```

## ✅ ШАГ 2: ЗАПУСК BACKEND НА ВАШЕМ КОМПЬЮТЕРЕ

### 2.1. Откройте PowerShell в папке проекта

```powershell
cd d:\табель
```

### 2.2. Проверьте файл .env

Создайте файл `.env` если его нет:

```env
# Database
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_DB=timesheet_db
DATABASE_URL=postgresql://postgres:postgres@db:5432/timesheet_db

# API
API_HOST=0.0.0.0
API_PORT=8000
DEBUG=True

# CORS - добавим amoCRM
CORS_ORIGINS=["http://localhost:3000","https://*.amocrm.ru","https://*.amocrm.com","https://*.ngrok.io"]
```

### 2.3. Запустите контейнеры

```bash
# Остановить старые контейнеры (если есть)
docker-compose down

# Запустить заново
docker-compose up -d

# Подождать 10 секунд для запуска базы данных
timeout /t 10

# Применить миграции
docker-compose exec backend alembic upgrade head
```

### 2.4. Проверьте работу

```bash
# Проверить статус
docker-compose ps

# Должно показать:
# backend  Up  0.0.0.0:8000->8000/tcp
# db       Up  5432/tcp
```

Откройте в браузере: **http://localhost:8000/docs**

Должна открыться документация API (Swagger).

## ✅ ШАГ 3: УСТАНОВКА И НАСТРОЙКА NGROK

ngrok создаст туннель: `интернет → ngrok → ваш компьютер:8000`

### 3.1. Скачайте ngrok

1. Перейдите на https://ngrok.com/download
2. Скачайте для Windows
3. Распакуйте ngrok.exe в удобное место (например, `C:\ngrok\`)

### 3.2. Зарегистрируйтесь (бесплатно)

1. Зарегистрируйтесь на https://dashboard.ngrok.com/signup
2. Получите ваш Authtoken
3. В PowerShell выполните:

```bash
C:\ngrok\ngrok.exe config add-authtoken ВАШ_ТОКЕН
```

### 3.3. Запустите ngrok

Откройте **НОВОЕ** окно PowerShell:

```bash
C:\ngrok\ngrok.exe http 8000
```

**ВАЖНО:** Это окно должно оставаться открытым всё время тестирования!

### 3.4. Скопируйте URL

В окне ngrok вы увидите:

```
Forwarding   https://abc123def456.ngrok.io -> http://localhost:8000
```

**Скопируйте этот URL:** `https://abc123def456.ngrok.io`

Это ваш публичный адрес на время тестирования.

## ✅ ШАГ 4: НАСТРОЙКА CORS В BACKEND

Нужно разрешить запросы от amoCRM и ngrok.

### 4.1. Откройте файл backend/app/main.py

Найдите секцию CORS (примерно строка 30-40):

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:3000",
        "https://*.amocrm.ru",
        "https://*.amocrm.com",
        "https://*.ngrok.io",  # ← Добавьте эту строку если её нет
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 4.2. Перезапустите backend

```bash
docker-compose restart backend

# Подождите 5 секунд
timeout /t 5
```

### 4.3. Проверьте доступность через ngrok

В браузере откройте: `https://ваш-ngrok-url.ngrok.io/docs`

Должна открыться та же документация API, что и на localhost.

## ✅ ШАГ 6: ЗАГРУЗКА ВИДЖЕТА В amoCRM

### 6.1. Откройте amoCRM

1. Войдите в ваш аккаунт amoCRM
2. Нажмите **⚙️ (Настройки)** в правом верхнем углу
3. Перейдите: **Настройки → Интеграции → Виджеты**

### 6.2. Загрузите виджет

1. Нажмите **"Добавить виджет"** или **"Загрузить свой виджет"**
2. Выберите файл: `timesheet_il_widget.zip` (в папке d:\табель)
3. Нажмите **"Загрузить"**
4. Дождитесь проверки (~10-30 секунд)

### 6.3. Настройте виджет

После успешной загрузки:

1. **Включите виджет** - переведите тумблер в положение "Вкл"
2. **Выберите разделы** где показывать виджет:
   - ✅ Карточка лида
   - ✅ Карточка контакта  
   - ✅ Карточка компании
   - ✅ Карточка сделки
3. Нажмите **"Сохранить"**

## ✅ ШАГ 7: ТЕСТИРОВАНИЕ ВИДЖЕТА

### 7.1. Откройте карточку

1. Перейдите в любую карточку (сделка/контакт/компания)
2. Посмотрите на **правую боковую панель**
3. Найдите виджет **"⏱️ Рабочее время"** или **"Timesheet IL"**

### 7.2. Тест 1: Начать рабочий день

1. Нажмите кнопку **"▶️ Начать рабочий день"**
2. Должно произойти:
   - Кнопка меняется на таймер
   - Таймер начинает считать: 00:00:01, 00:00:02...
   - Появляются кнопки "⏸️ Перерыв" и "⏹️ Завершить"

**Если не работает:**
- Откройте консоль браузера (F12)
- Посмотрите на ошибки (красный текст)
- Проверьте, что ngrok работает
- Проверьте URL в виджете

### 7.3. Тест 2: Перерыв

1. Нажмите **"⏸️ Перерыв"**
2. Должно произойти:
   - Статус меняется на "На перерыве"
   - Таймер показывает оранжевый цвет
   - Кнопка меняется на "▶️ Возобновить"

### 7.4. Тест 3: Возобновление

1. Нажмите **"▶️ Возобновить"**
2. Должно произойти:
   - Статус "Работает"
   - Таймер продолжает считать

### 7.5. Тест 4: Завершить день

1. Нажмите **"⏹️ Завершить день"**
2. Должно произойти:
   - Появляется сводка (время работы, перерывы)
   - Кнопка возвращается к "▶️ Начать рабочий день"

### 7.6. Проверка в базе данных

Проверьте, что данные сохранились:

```bash
docker-compose exec db psql -U postgres -d timesheet_db -c "SELECT * FROM work_sessions ORDER BY id DESC LIMIT 5;"
```

Должна показаться таблица с вашими сессиями.

## 🐛 РЕШЕНИЕ ПРОБЛЕМ

### Проблема 1: Виджет не загружается в amoCRM

**Причины:**
- Размер архива > 2MB
- Неправильная структура файлов
- Ошибка в manifest.json

**Решение:**
```bash
# Проверьте размер
dir timesheet_il_widget.zip

# Проверьте содержимое
Expand-Archive -Path timesheet_il_widget.zip -DestinationPath temp_check
dir temp_check
```

### Проблема 2: "Ошибка подключения к API"

**Причины:**
- ngrok не запущен
- Backend не запущен
- Неправильный URL в виджете
- CORS не настроен

**Решение:**
```bash
# Проверьте backend
docker-compose ps

# Проверьте ngrok
# Окно с ngrok должно быть открыто!

# Проверьте доступность
curl https://ваш-url.ngrok.io/api/v1/health
```

### Проблема 3: CORS ошибка

**Ошибка в консоли:** "Access-Control-Allow-Origin"

**Решение:**
1. Добавьте в backend/app/main.py:
   ```python
   allow_origins=["https://*.ngrok.io", "https://*.amocrm.ru"]
   ```
2. Перезапустите: `docker-compose restart backend`

### Проблема 4: ngrok "Session Expired"

**Причина:** Бесплатный туннель живёт 2 часа

**Решение:**
1. Перезапустите ngrok
2. Скопируйте новый URL
3. Пересоберите виджет: `.\build_widget.ps1 -ApiUrl "новый-url"`
4. Загрузите в amoCRM заново

### Проблема 5: База данных не отвечает

**Решение:**
```bash
# Перезапустите всё
docker-compose down
docker-compose up -d

# Подождите 10 секунд
timeout /t 10

# Примените миграции
docker-compose exec backend alembic upgrade head
```

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### О ngrok в бесплатной версии:

1. **Туннель живёт 2 часа** - потом нужно перезапускать
2. **URL меняется** при каждом перезапуске
3. **После перезапуска** нужно пересобрать виджет
4. **Для production** нужен постоянный сервер

### О безопасности:

⚠️ **Ваш компьютер временно доступен из интернета!**

Безопасно для тестирования, но:
- Не храните важные данные
- Используйте тестовые данные
- После тестирования закройте ngrok (Ctrl+C)
- Не оставляйте ngrok запущенным надолго

### О производительности:

- Ваш компьютер должен быть включен
- Должен быть интернет
- Backend и ngrok должны работать
- Docker должен работать
