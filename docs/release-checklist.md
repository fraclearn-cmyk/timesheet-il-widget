## Controlled live amoCRM — внешний gate

Проводить только при подтверждённой авторизованной Chrome-сессии и текущем доступном
локальном HTTPS API. Использовать тестового сотрудника/группу, сохранить исходные значения.

1. Загрузить проверенный ZIP и сохранить текущий API URL в native настройках amoCRM.
2. Администратор: настройки виджета → «Настройки» → предел перерыва группы (по умолчанию 60,
   допустимо 1..720); «Пользователи» → активная группа → «Объяснительная при опоздании».
   Сохранить и открыть повторно. Руководителю и сотруднику эти настройки недоступны.
3. Сотрудник: поздно начать день; пустая/пробельная причина оставляет серую отключённую кнопку.
   Причина до 1000 символов делает кнопку синей; отправка создаёт одну смену/одно событие.
4. Превысить лимит перерыва: «Продолжить работу» требует причину, до отправки статус остаётся
   «На перерыве». Повтор команды не дублирует событие. Проверить второй поздний перерыв,
   точную границу без опоздания и серверный конфликт после смены времени.
5. Руководитель видит только свою группу, администратор — аккаунт, сотруднику отчёт запрещён.
   В блоке «Опоздания» четыре поля: «Начало дня → Минуты / Объяснительная»,
   «Перерыв → Минуты / Объяснительная». Два превышения 8 и 5 минут дают 13 и две причины.
6. Выбрать четыре поля Excel независимо; полная выгрузка имеет три строки заголовков,
   целые минуты, переносы текста, безопасные HTML-подобные причины и формульные префиксы.
   Переполнение выводит маркер и полный лист «Объяснительные».
7. При сбое API нет ложного подтверждения работы. Проверить callbacks, повторное открытие,
   сохранение, focus/CORS и удаление ресурсов при destroy. Восстановить настройки и тестовые данные.

Результат локального браузерного теста не считается этим live gate.
