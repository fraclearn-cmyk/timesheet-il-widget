# Матрица требований виджета «Табель»

Источник: согласованные требования пользователя и текущая структура проекта на 2026-09-11.

| Область | Требование | Текущий задел | Планируемая реализация | Проверка |
|---|---|---|---|---|
| Установка | Рабочий `widget.zip` уже загружается в amoMarket | Есть распакованный каталог `widget/` | Сохранять совместимый manifest и архивную структуру | Проверка архива и загрузка в тестовый аккаунт |
| Настройки | В amoMarket только вкладки «Настройки» и «Пользователи» | Есть `advanced_settings`, callback settings | Сделать редактор пользователей, групп, статусов и расписания | Smoke-тест настройки |
| Доступ | Источник прав — amoCRM | Есть локальные enum roles и RBAC-задел | Серверная проверка контекста amoCRM | API 401/403 сценарии |
| Пользователи | «Учитывать рабочее время» | Поля полностью нет | Добавить настройку членства и синхронизацию пользователей | Сохранение/перезагрузка |
| Видимость | «Скрыть виджет» не выключает учёт | Есть только общий overlay | Отдельные `track_time` и `hide_widget` | Скрытый пользователь продолжает попадать в отчёт |
| Группы | Группы отдельные от отделов amoCRM; один сотрудник в одной группе | Есть departments, отдельной модели групп нет | `WidgetGroup` и уникальное членство | Конфликт второй группы |
| Расписание | Часовой пояс, начало и конец дня на группу | В department есть время, timezone нет | Поля группы и UTC-хранение | Тест перехода через DST/часовой пояс |
| Статусы | Работаю, Перерыв, Закончил(а) | Есть `WorkStatus` и sessions | Единый state machine и разрешение повторного запуска | Unit/API тесты переходов |
| Блокировка | Вне `Работаю` тёмный полупрозрачный overlay | Есть overlay в `widget/script.js` | Убрать demo fallback и оставить только разрешённые кнопки | Browser smoke-тест |
| Активность | Только события amoCRM и звонки | Есть enum activity, нет интеграции | Нормализатор событий, ingestion, дедупликация | Mock contract tests |
| Интервалы | Порог бездействия 5 минут; мышь/клавиатура без CRM-результата не зелёные | Есть inactivity timeout 300 секунд | Разделить confirmed/unconfirmed/idle intervals | Unit-тесты интервалов |
| Мониторинг | Admin все, руководитель своя группа, employee только себя | Есть team API, но структуры не согласованы | Единый API visibility policy | RBAC integration tests |
| Активность 7 дней | Гамбургер напротив сотрудника, tooltip и zoom | Есть timeline API-задел | Modal/fullscreen timeline с зелёными полосками | Browser test |
| Табель | Начало, конец, перерывы, работа, опоздание, статус | Есть reports/excel-задел | Detailed report до 3 месяцев | API/report tests |
| Excel | Активность в Excel не выводится | Excel service заявлен, есть ошибки полей | Стабильный табельный экспорт без CRM activity | Открытие XLSX и проверка колонок |

## Внешние зависимости

- Для проверки реальных OAuth, аналитики событий, звонков и прав нужен тестовый amoCRM-аккаунт с установленным виджетом.
- В текущем workspace нет `widget.zip`; исходником считается каталог `widget/`. Перед публикацией архив нужно собрать из него и проверить содержимое.
- Доступность полного списка событий стандартной аналитики amoCRM нельзя подтвердить только локальным кодом; до получения тестовых ответов используется mock-контракт и статус ограничения.
